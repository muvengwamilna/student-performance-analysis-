# Project 1: Student Performance Data Analysis

## 1. Introduction
This project uses a small student dataset to explore academic performance. I wanted to understand whether attendance and study time appear to be related to students' exam results.

The dataset is **synthetic** and was created for learning purposes. It does not contain real student information.

## 2. Problem Statement
Universities collect academic information such as attendance, study time and marks. Looking at this information can help identify patterns in student performance.

## 3. Objectives
- Load and inspect student data.
- Check for missing values.
- Calculate simple statistics.
- Compare attendance with exam performance.
- Compare study hours with exam performance.
- Identify useful patterns in the data.

## 4. Tools Used
- Python
- Pandas
- Matplotlib

## 5. Dataset
The dataset contains:
- Student ID
- Gender
- Attendance percentage
- Study hours per week
- Assignment score
- Exam score

## 6. Steps Followed
1. Imported the dataset.
2. Checked the first few rows.
3. Checked the dataset size.
4. Checked for missing values.
5. Calculated summary statistics.
6. Calculated average values.
7. Identified students scoring at least 50%.
8. Created simple scatter plots.
9. Interpreted the results.

## 7. Main Findings
The analysis can be used to observe whether higher attendance and more study time tend to occur alongside higher exam scores. Because the dataset is synthetic and small, the results should be treated as a learning exercise rather than evidence about real students.

## 8. Conclusion
This project helped me practise loading data, checking data quality, calculating statistics and creating simple visualisations. It also showed me how data analysis can be used to look for patterns in academic information.

## 9. Limitations
- The dataset is synthetic.
- It contains only 80 students.
- It does not include every factor that can affect academic performance.
- A relationship in the data does not automatically mean one factor causes another.

## 10. Future Improvements
In future, I would use an approved real-world dataset and include more variables such as previous grades, course workload and access to learning resources.
