# PROJECT REPORT: STUDENT PERFORMANCE DATA ANALYSIS

## 1. Introduction
As a Data Science and Informatics student, I wanted to practise using data to understand a simple real-world problem. I chose student performance because academic information can contain useful patterns. In this project, I looked at attendance, study hours, assignment scores and exam scores.

The dataset used in this project is synthetic. It was created only for learning and demonstration, so no real student's private information is used.

## 2. Problem Statement
It can be difficult to understand student performance by looking at individual marks only. Data analysis can help identify patterns between different academic factors.

## 3. Aim
The aim is to analyse student information and explore whether attendance and study time are associated with exam performance.

## 4. Objectives
- Load student data using Python.
- Check the data for missing values.
- Calculate basic statistics.
- Compare attendance with exam scores.
- Compare study hours with exam scores.
- Present findings using simple graphs.

## 5. Tools
Python, Pandas and Matplotlib.

## 6. Method
The dataset was loaded into Pandas. I inspected the first records and checked for missing values. I then calculated averages and summary statistics. Finally, I used scatter plots to compare attendance and study hours with exam scores.

## 7. Results and Discussion
The program prints the averages and creates two graphs. These graphs help show whether students with higher attendance or more study time generally have higher exam scores.

Because the dataset is synthetic, the results should not be used to make decisions about real students.

## 8. Conclusion
The project gave me practical experience in data loading, data checking, basic statistical analysis and visualisation. It also helped me understand how Python can be used to investigate a simple academic problem.

## 9. Limitations
The dataset is synthetic and relatively small. Other important factors, such as previous academic performance and personal circumstances, are not included.

## 10. Future Work
A future version could use an approved real dataset, include more variables and use statistical tests to investigate the relationships more carefully.
